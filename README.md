# AI PrepPulse - Interview Readiness Checker

Helper tool for students to assess their Interview Readiness in under 2 minutes.
Hackathon MVP.

## 🚀 Features
- **Assess Technical Skills**: Rate your stack familiarity and projects.
- **Resume & Experience**: Checks if your resume is mentored-reviewed.
- **AI-Powered Feedback**: Personalized action plan based on your score.
- **Instant Result**: No login, no signup, just value.

## 🛠️ Tech Stack
- **Frontend**: Next.js 14, React, Tailwind CSS
- **Styling**: Glassmorphism UI, Lucide Icons, Framer Motion (animate-in)
- **Logic**: Rule-based scoring engine

## 🏁 How to Run Locally

1. **Clone & Install**
   ```bash
   git clone <repo-url>
   cd ai-preppulse
   npm install
   ```

2. **Run Dev Server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000).

3. **Build fo Production**
   ```bash
   npm run build
   npm start
   ```

## 📊 How Scoring Works
- **Technical Skills (30%)**: Based on your confidence + # of projects.
- **Resume Quality (20%)**: High weightage on whether it's reviewed by a mentor.
- **Communication (25%)**: Soft skills confidence + mock interviews.
- **Portfolio (25%)**: Existence of a showcase link.
